Place Phantom UI assets here.

Folders:
- footer-icons
  Use for the footer SVGs you mentioned:
  home.svg
  cards.svg
  swap.svg
  chat.svg
  search.svg

- asset-images
  Use for fixed token/app images you want to override manually.
  Example:
  solana.png
  ethereum.png
  bitcoin.png

- reference
  Use for exact screenshot/reference images if you want them kept in-project.

Notes:
- For custom/memecoin assets, the app can keep using Dexscreener image URLs.
- Manual images in `asset-images` are best for the fixed Phantom default assets when you want exact logo matching.
